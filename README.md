# Enterprise Network

Small enterprise network created in Cisco Packet Tracer.

## Description

The network is divided into departments using VLANs.  
Inter-VLAN routing is configured using Router-on-a-Stick.

## VLANs

| VLAN | Department | Network |
|---|---|---|
| 10 | IT | 192.168.10.0/24 |
| 20 | Accounting | 192.168.20.0/24 |
| 30 | HR | 192.168.30.0/24 |
| 40 | Management | 192.168.40.0/24 |
| 50 | Servers | 192.168.50.0/24 |

## Technologies

- Cisco Packet Tracer
- Cisco IOS
- VLAN
- 802.1Q Trunking
- Inter-VLAN Routing
- IPv4

## Result

- VLANs configured
- Trunk connections configured
- Inter-VLAN routing works
- Server connectivity verified
- Configuration saved
